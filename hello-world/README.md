# Hello World

"Hello, World!" in a bunch of languages. Each file prints the same line.

| Language   | File          | Run                                  |
|------------|---------------|--------------------------------------|
| Python     | `hello.py`    | `python3 hello.py`                   |
| JavaScript | `hello.js`    | `node hello.js`                      |
| TypeScript | `hello.ts`    | `ts-node hello.ts`                   |
| Go         | `hello.go`    | `go run hello.go`                    |
| Rust       | `hello.rs`    | `rustc hello.rs && ./hello`          |
| Java       | `Hello.java`  | `java Hello.java`                    |
| C          | `hello.c`     | `cc hello.c -o hello && ./hello`     |
| C++        | `hello.cpp`   | `c++ hello.cpp -o hello && ./hello`  |
| C#         | `Hello.cs`    | `dotnet run` / `csc Hello.cs`        |
| Ruby       | `hello.rb`    | `ruby hello.rb`                      |
| PHP        | `hello.php`   | `php hello.php`                      |
| Bash       | `hello.sh`    | `bash hello.sh`                      |
| Kotlin     | `hello.kt`    | `kotlinc hello.kt -include-runtime -d h.jar && java -jar h.jar` |
| Swift      | `hello.swift` | `swift hello.swift`                  |
| Lua        | `hello.lua`   | `lua hello.lua`                      |
| Perl       | `hello.pl`    | `perl hello.pl`                      |
| Racket     | `hello.rkt`   | `racket hello.rkt`                   |
| Scala      | `hello.scala` | `scala hello.scala`                  |
| Haskell    | `hello.hs`    | `runghc hello.hs`                    |
| Elixir     | `hello.ex`    | `elixir hello.ex`                    |
| Dart       | `hello.dart`  | `dart hello.dart`                    |
| R          | `hello.r`     | `Rscript hello.r`                    |
